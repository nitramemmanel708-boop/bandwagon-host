# 搬瓦工购买与套餐选择指南

搬瓦工（BandwagonHost）是加拿大 IT7 Networks 旗下的海外 VPS 服务商，提供基于 KVM 架构的虚拟服务器。购买 VPS 后，用户需要自己管理系统和服务器环境；如果你希望选择配置、机房并通过 SSH 管理服务器，这类产品值得了解。首次接触时，除了价格，也要考虑可用机房、流量、付款周期，以及自己是否准备好维护系统和数据。

这篇指南整理参考资料中的访问入口、六款套餐和购买步骤，帮助你先比较需求，再到产品页面核对订单。表内配置、价格与机房范围均为参考资料所列，并非实时库存或现价；实际可购买内容以对应页面和结账信息为准。

## 访问入口与注册准备

参考资料列出的搬瓦工官网主域名为 `bandwagonhost.com`，另有 `bwh81.net`、`bwh1.net`、`bwh8.net`、`bwh88.net` 和 `bwh89.net` 等镜像域名。访问情况可能因网络环境而不同；打开页面后，先确认自己进入的是预期的服务与账号页面，再填写信息。

也可以通过[套餐总览与注册入口](https://bit.ly/BanWaGon)查看在售方案。这个入口适合先浏览；下表中的独立链接则分别对应具体产品，选定后应再次核对名称与配置。

注册前准备一个能接收邮件的邮箱、密码及账单信息。邮箱之后用于接收服务器相关信息，因此应确保自己能够登录并查看。注册时按页面要求填写资料，尤其注意账单国籍等字段；参考资料提到国籍会影响后台税率显示。

如果订单被拒，参考资料提及访问 IP 与填写的账单信息不一致可能是原因之一，但不能据此判断每一次拒单的原因。先检查所填信息和订单提示；仍无法解决时，可联系官方支持确认，不要反复提交未经核对的信息。

### 各项配置怎样影响选择

- **CPU 和内存**：先估计要运行的程序以及同时运行的任务，再比较核心数和内存。GIA-E 标准款比入门款多一个核心，但同为 1GB 内存；如果主要顾虑是内存，仅看核心数并不能解决选择问题。
- **SSD 容量**：硬盘空间需要容纳系统、程序和数据。比较 20GB、40GB、80GB 时，应给系统和后续数据增长留出空间，而不是只按现有文件大小选购。
- **月流量**：它是一个计量周期内的数据传输额度，不等同于硬盘容量。流量需求要结合访问量和传输内容估算；参考表中香港入门为 500GB，而 GIA-E 入门为 1TB，应把额度和价格一起看。
- **带宽**：表中 1Gbps 或 2.5Gbps 是标称带宽，不等于每次连接都能达到的实际速度。使用时的网络路径、访问者所在地等因素也值得考虑。
- **独立 IPv4 与面板**：表中每款都列有独立 IPv4 和 KiwiVM 功能，因此比较这六款时，更有区分度的通常是配置、流量、机房和费用。

预算是首要约束时，可以先看基础款：参考年价低于表中的 GIA-E 与香港方案，但所列机房范围是欧美普通机房。它与 GIA-E 入门款的 CPU、内存、硬盘和月流量相同，区别不能只看配置数字，还要看机房范围、带宽和价格。

如果希望比较更多机房，CN2 GIA-E 系列提供了参考资料所列的 12 个选项。入门款与标准款同为 1GB 内存，标准款增加了核心、硬盘和流量；高配款则进一步增加内存、核心和容量。选择时先确定资源是否需要，再看较高价格和可选付款周期是否符合预算。

需要香港机房时，可以单独比较两款香港 CN2 GIA：标准款的内存、硬盘和流量高于入门款，价格也更高。香港方案并非只凭名称就适合所有用途，应同时核对机房范围、月流量和费用，再决定是否有必要为该地区付出更多预算。

## 搬瓦工机房怎么选

机房选择关系到服务器所在地区和网络路径。参考资料列出的 GIA-E 选项包括洛杉矶 DC6、DC9，日本软银 JPOS_1，以及荷兰 EUNL_9；香港方案还涉及 HKHK_8。不同套餐的可选范围不同，不能因为某个机房出现在一款产品中，就假定所有产品都能选。

可以先写下主要访客在哪里、使用哪些运营商，以及可接受的预算。如果服务的访问者分布在不同地区，应分别考虑他们的访问情况，而不是只根据服务器所在地判断速度。参考资料将 DC6 与电信、移动用户的选择联系起来，也提到日本软银和荷兰机房供联通用户比较；这些只是初步筛选线索，不是对任何用户延迟或稳定性的保证。

对于搬瓦工 CN2 GIA-E，参考资料称可在 KiwiVM 中切换机房，并提示迁移需要重新安装系统。因此，计划迁移时先确认目标机房是否在当前套餐的可选列表中，备份需要保留的数据，再核对面板中的迁移条件和操作提示。不要把“可以切换”理解为数据会自动保留，也不要等到开始重装后才考虑备份。

## 搬瓦工购买教程：从注册到连接

1. **进入并浏览产品**：通过[套餐总览](https://bit.ly/BanWaGon)查看可选方案，或从上表进入具体产品。先确认产品名称、配置、机房范围与自己的需求一致。
2. **注册账号**：进入注册页面，按要求填写邮箱、密码和账单资料。检查邮箱拼写与账单国籍，避免后续无法接收信息或因资料不一致影响订单处理。
3. **核对订单**：将所选套餐加入购物车后，检查 CPU、内存、硬盘、流量以及账单周期。特别注意月付、季付和年付显示的是不同周期的金额；不要把季度价格误当成年费。
4. **选择机房并结账**：按页面提供的选项选择机房，复核商品、价格、周期和账单信息。参考资料列有支付宝、PayPal 和信用卡付款方式，实际选项以结账页面为准。
5. **查收服务器信息**：付款后留意注册邮箱。参考资料提到邮件包含 VPS IP 和 KiwiVM 后台链接；若未找到，先检查邮箱中的相关邮件，再通过官方支持渠道询问。
6. **登录并连接**：使用收到的信息登录 KiwiVM，在面板中设置 root 密码，然后通过 SSH 连接服务器。连接前确认使用的是邮件中的正确 IP，并妥善保管账号和密码。

完成首次登录后，先熟悉面板中的系统重装、快照和流量查看位置，再开始自己的服务器配置。重装或机房迁移会涉及系统操作，应先确认数据已备份并读懂面板提示。

## 付款周期、退款与选购提醒

月付、季付和年付的主要区别是每次付款覆盖的时间与单次支出。周期较短便于先控制一次性支出，年付则需要一次承担更长周期的费用；两者应按产品页面实际金额比较，而不是假定每款都有相同选项。表中基础款列的是年付，GIA-E 入门和标准列有季付与年付，高配和香港方案则列有月付与年付。

参考资料提到 30 天内可以申请退款，但这不是对所有订单无条件退款的保证。付款前应查看适用条款，了解申请条件及处理方式；如果退款条件对决定是否购买很重要，先确认清楚再下单。

参考资料还提及限量套餐和促销。库存、价格及优惠是否适用都需要在购买时核对；没有确认的优惠码不应计入预算。最终选择可以回到三个问题：基础款的机房是否满足需求，是否需要 GIA-E 所列的更多机房，以及香港方案的地区与资源是否值得其价格。确认这些，再核对对应产品页面和结账信息即可。
